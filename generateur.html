Installation par client mail

Outlook classique — Windows
  1. Renseignez l'URL d'hébergement (étape 5), puis cliquez Copier la signature.
  2. Outlook › Fichier › Options › Courrier › Signatures… › Nouveau, nommez-la « LEKO ».
  3. Collez (Ctrl+V) dans la zone d'édition, enregistrez, définissez-la par défaut pour les nouveaux messages et les réponses.
  4. Alternative « propre » (recommandée pour le thème automatique) : Télécharger signature.htm, puis remplacer le fichier LEKO.htm dans %APPDATA%\Microsoft\Signatures\, Outlook fermé.
Nouveau Outlook — Windows & Outlook — Mac
  1. Copier la signature dans ce générateur.
  2. Outlook › Paramètres (⚙) › Comptes › Signatures › + Nouvelle signature.
  3. Collez dans l'éditeur, enregistrez, choisissez-la pour les nouveaux messages et les réponses/transferts.
Gmail (web)
  1. Les images doivent être hébergées (étape 5). Cliquez Copier la signature.
  2. Gmail › ⚙ › Voir tous les paramètres › Général › Signature › + Créer.
  3. Collez dans la zone, puis « Enregistrer les modifications » en bas de page.
Apple Mail — macOS
  1. Cliquez Copier la signature.
  2. Mail › Réglages › Signatures › sélectionnez le compte › +.
  3. Décochez « Toujours utiliser la police par défaut » puis collez (⌘V) dans la zone de droite.
  4. Si l'aperçu semble tronqué dans les réglages, c'est normal : envoyez-vous un test.
iPhone / iPad (Mail, Outlook mobile)
  1. Envoyez-vous un mail depuis un ordinateur avec la signature, ouvrez-le sur le téléphone.
  2. Sélectionnez la signature dans le mail, copiez, puis collez dans Réglages › Mail › Signature (ou Outlook mobile › Paramètres › Signature).
